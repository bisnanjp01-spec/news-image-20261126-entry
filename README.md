# The World in One Day — Thursday 26 November 2026

A newspaper front page that sums up one day of world news in a single
image: **Thursday 26 November 2026**.

The front page carries four stories from that day, each with its own
illustration, headline and one-line caption:

1. **Tariffs for fourteen nations** — Washington proposes new tariffs
   on 14 trading partners to fight excess factory capacity, with the
   highest rates hitting China.
2. **Kim orders more nuclear arms** — North Korea's leader tours
   nuclear-material and weapons research sites and calls for tactical
   nuclear weapons to be deployed more widely.
3. **Huawei guilty on ten counts** — a New York jury convicts Huawei
   of conspiring to steal US trade secrets, bank and wire fraud, and
   violating sanctions on Iran; sentencing is set for September 2027.
4. **Riyadh tower hit again** — a Houthi drone strikes the PIF Tower,
   the Saudi capital's tallest building, for the second time in under
   a week, wounding 11 people.

A footer ticker adds the day's other headlines: Sudan strikes killing
19 civilians, Xi's graft probe of Shanghai's party chief, Merz backing
Ukraine aid, and the US famine monitor halting its reports.

## How to run

Requires Node 22. The program writes `entry.png` (stored in this
repository) to the output directory, byte for byte:

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

The output is written to `$MAKEFUN_OUTPUT_DIR/entry.png`
(`/output/entry.png` by default). The program is deterministic: it
uses only the Node standard library, makes no network requests, and
contains no randomness or timestamps, so repeated runs produce
byte-identical output.
